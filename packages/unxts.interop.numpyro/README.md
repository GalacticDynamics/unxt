# unxts.interop.numpyro

NumPyro integration for [unxt](https://github.com/GalacticDynamics/unxt).

This package will let NumPyro models take `unxt` quantities. It is a skeleton for now and exports nothing yet.

## Install

```bash
pip install unxts.interop.numpyro
```

## Usage

```python
import unxts.interop.numpyro
```
